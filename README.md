An entry for the make.fun contest "The Houseplant Out-of-Office" — the funniest one-line out-of-office auto-reply a houseplant would send, 120 characters or fewer. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes exactly one line to `/output/entry.txt`: a fern, unwatered since March, announcing that neither it nor its owner is coming back from this.
